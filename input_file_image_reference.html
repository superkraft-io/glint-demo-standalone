input[type="file"] and input[type="image"] browser reference

This page is a plain browser reference for file pickers and image-submit controls before implementing Glint parity. Use it to inspect event order, reset behavior, submitted values, and the browser's restrictions around programmatic file input changes.

  • Pick files and compare the files list against the displayed previews and form serialization.
  • Use the programmatic test buttons to observe what browsers allow or reject on type="file".
  • Click the image inputs in different spots to inspect submitted name.x and name.y coordinates.
